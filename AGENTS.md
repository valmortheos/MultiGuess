- Modul Python lain di `/modules/`.
- Client JS di `/static/`, template di `/templates/`.
- Sound assets di `/Sound/`.
- Cache server di `/cache/` (auto-created).
- Setiap perubahan wajib additive-only (comment out kode lama, jangan hapus).
- Verifikasi `git diff --stat` → added > deleted sebelum commit.
